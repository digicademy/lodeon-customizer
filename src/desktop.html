LODEON Customizer Help

Connect a workbench

Save the address of your LODEON instance in the header. In that LODEON tab, open Settings → Customize Workbench → Connect. The green Connected chip shows that a tab has connected to this Customizer.

Configure models

Add your own models and brokers under Personal models. Under Instance models, choose Edit settings to set temperature or Top P. Clear a field to use the instance value again.

Use Local package to choose a folder or reload settings edited on disk. Read the full user guide
